
# AdvisoryAtlas – 10 Test Questions

These questions will be used to evaluate whether AdvisoryAtlas can identify vulnerabilities and correctly determine affected product versions.

## Product and vulnerability questions

1. Is FortiOS version 7.0.11 affected by the vulnerability described in a CERT-In advisory?

2. Is FortiOS version 7.2.1 affected by the same vulnerability?

3. Which Windows Server versions are affected by a particular CERT-In vulnerability note?

4. What is the CERT-In vulnerability note ID associated with a reported vulnerability?

5. What fix or security update is recommended for an affected product?

## Hospital IT administrator questions

6. Are any of the registered hospital IT products affected by recent CERT-In advisories?

7. Which vulnerabilities affect the Windows servers registered in the hospital's technology stack?

8. Are the registered Fortinet firewall versions affected by any published vulnerability notes?

9. Which vulnerabilities require the administrator to check manually because the affected version range is unclear?

10. What CERT-In advisories or vulnerability notes should the hospital administrator review to identify relevant security updates?
